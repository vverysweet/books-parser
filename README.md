# Парсер книг

Собирает названия и цены книг с books.toscrape.com и сохраняет в Excel.

## Стек
- Python
- requests
- BeautifulSoup
- pandas
- openpyxl

## Как запустить
1. Установи зависимости:
   pip install requests beautifulsoup4 pandas openpyxl
2. Запусти:
   python book_parser.py
3. Результат: all_books.xlsx
